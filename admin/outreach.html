برای هر رزومه یا پیام یک لینک اختصاصی بساز. کد لینک در آمار ثبت می‌شود؛ نام شرکت، گیرنده و یادداشت‌ها فقط در همین مرورگر می‌مانند.

۰ لینک

هنوز لینکی ذخیره نشده. اولین ارسال را از فرم کنار صفحه بساز.

رایگان و محلی

این فهرست به CMS، گیت‌هاب یا دیتابیس ارسال نمی‌شود. برای مرورگر یا دستگاه دیگر، پشتیبان JSON بگیر و آنجا بازیابی کن. پاک کردن داده‌های مرورگر، این فهرست را هم پاک می‌کند. فایل پشتیبان را خصوصی نگه دار.

آمار هر لینک را کجا ببینم؟

این صفحه لینک‌ها و یادداشت‌های تو را نگه می‌دارد. آمار بازدید در پراپرتی جدید GitHub Pages New در Google Analytics است؛ به این فهرست به‌صورت خودکار برنمی‌گردد.

راه‌اندازی گزارش، فقط یک بار
  1. در پراپرتی جدید به Admin → Data display → Custom definitions برو.
  2. سه Custom dimension با Scope: Event بساز: outreach_id (کد ارسال)، section_name (بخش سایت)، item_id (پروژه یا مقاله). نام دلخواه است؛ Event parameter باید دقیقاً همین کد باشد.
  3. یک Custom metric برای پارامتر active_seconds با واحد Seconds و Scope رویداد بساز.
  4. در Explore → Free form، کد ارسال و بخش سایت را به Rows و Event name را به Columns اضافه کن. Values را روی Event count بگذار؛ برای زمان توجه، گزارش جداگانه‌ای با فیلتر section_attention و معیار زمان فعال بساز.
  5. برای یک ارسال، فیلتر کد ارسال را برابر کدی بگذار که از این صفحه کپی کردی. تعریف‌های جدید ممکن است ۲۴ تا ۴۸ ساعت زمان بخواهند و روی داده‌های قدیمی اعمال نمی‌شوند.
هر رویداد چه معنایی دارد؟
section_view
یک بخش در تب فعال مرورگر و داخل محدودهٔ قابل دیدن صفحه نمایش داده شده.
section_attention
زمان فعال هر بخش؛ تب پنهان، پنجرهٔ غیرفعال و بیش از ۶۰ ثانیه بی‌تعاملی شمرده نمی‌شوند. این تخمین توجه است، نه اثبات خواندن.
section_engaged
زمان فعال یک بخش به ۱۰، ۳۰، ۶۰ یا ۱۲۰ ثانیه رسیده.
section_depth
عمق قابل مشاهدهٔ محتوا به ۲۵، ۵۰، ۷۵ یا ۱۰۰ درصد رسیده؛ روی موبایل و پنل اسکرول دسکتاپ محاسبه می‌شود.
project_click / publication_click
کلیک روی لینک پروژه یا مقاله، با کد همان آیتم.
contact_click
کلیک روی GitHub، LinkedIn یا ایمیل؛ به معنی ارسال پیام نیست.
article_expand
متن کامل یک پست باز شده.

بازدید ثبت‌شده یعنی لینک استفاده شده؛ ممکن است فوروارد شده باشد. نبود آمار به معنی «باز نشده» نیست. آمار فقط پس از اجازهٔ بازدیدکننده ثبت می‌شود و مسدودکننده‌ها هم می‌توانند آن را متوقف کنند. وضعیت هر ارسال در این فهرست را خودت ثبت می‌کنی.
